# WealthPlay — runtime dependencies.
#
# Pinned exactly so a clean clone reproduces the environment that was tested.
# Install:  pip install -r requirements.txt   (Python 3.12+)
#
# This is the deployable set, and it is deliberately the smaller one. Serverless
# hosts cap an unzipped function at 250 MB; this comes to roughly 200 MB, and
# the ASGI and worker stacks that used to sit here accounted for about 80 MB
# while serving no route the app actually has.
#
# Daphne, Channels, Twisted and Celery now live in `requirements-asgi.txt`.
# Install that as well on a host that runs a long-lived ASGI process or a
# scheduled worker. Nothing in the code requires them: `settings.py` adds the
# apps only when they import, and `wealthplay/__init__.py` skips Celery when it
# is absent.
