# WealthPlay — runtime dependencies.
#
# Pinned exactly so a clean clone reproduces the environment that was tested.
# Install:  pip install -r requirements.txt   (Python 3.12+)
#
# This is the deployable set, and it is deliberately small. A serverless
# function is capped at 225 MB unzipped; this comes to roughly 70 MB.
#
# Two things used to sit here and no longer do:
#
# * The ASGI and worker stacks — Daphne, Channels, Twisted, Celery — about
#   80 MB serving no route the app actually has, since there are no WebSocket
#   consumers. They moved to `requirements-asgi.txt`.
# * pandas and numpy, 119 MB, pulled in by `yfinance` to read a few hundred
#   numbers out of a JSON response. The provider's JSON endpoints are called
#   directly now; see `market_data/services.py`.
#
# Nothing in the code requires the absent packages: `settings.py` registers
# Daphne and Channels only when they import, and `wealthplay/__init__.py` skips
# Celery when it is missing.

# --- Database ----------------------------------------------------------------
# SQLite locally; psycopg is used when DATABASE_URL points at Postgres, which is
# required in production because a serverless filesystem does not persist.

# --- Cache -------------------------------------------------------------------
# No client here. Without REDIS_URL the database cache is used, which is the
# right choice on serverless anyway. For Redis, add `redis==7.4.0`.

# --- Market data -------------------------------------------------------------
# curl_cffi rather than plain requests for the provider: Yahoo rejects a stock
# HTTP client on its TLS fingerprint, and `impersonate` is what gets past that.
# It is the only part of yfinance that was actually load-bearing.
curl_cffi==0.13.0
cffi==2.0.0
pycparser==3.0
