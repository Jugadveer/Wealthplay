# Optional: the ASGI server and the background worker.
#
#   pip install -r requirements.txt -r requirements-asgi.txt
#
# Install these on a host that runs a long-lived process — Railway, Render, Fly,
# a VM — where `Procfile` can serve through Daphne and Celery Beat can run the
# two scheduled jobs.
#
# They are not in the base file because a serverless deployment can use none of
# them and they cost about 80 MB against a 250 MB function limit. Nothing breaks
# without them: `settings.py` registers Daphne and Channels only when they
# import, and `wealthplay/__init__.py` skips Celery when it is absent.
#
# There are currently no WebSocket routes — see `wealthplay/asgi.py`. Channels
# stays configured so that adding one later is a routing change rather than a
# deployment change.
